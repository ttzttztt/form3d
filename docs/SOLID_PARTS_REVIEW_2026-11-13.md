# 独立部件重建、完整圆柱抱枕与多家具复测报告

日期：2026-11-13。[图片与证据总览](../experiments/solid_parts_20261113/index.html)。[已保存的皮革沙发测试任务](http://127.0.0.1:8001/?job=56e8ad5b5ae240d1ba29da88d68ae920)。

## 本轮结论

新增“生成独立部件预览”，把已保存的 AI 表面分组转成可单独移动、换材质、导出的闭合候选。保持一组一个逻辑部件，补面不会在清单中变成额外零件。完整圆柱抱枕已在真实浏览器流程中生成、换材质和下载。

**当前仍未达到任意家具自动、准确、完整拆分的验收标准。** 两款沙发和一把休闲椅共 11 组，8 组的导出文件通过闭合、单一连通体、正体积及自交检查；其余 3 组保留源表面。闭合候选中仍有语义误分、边缘杂片和形变。不能把 8/11 写成部件识别准确率，更不能称为商品级验收通过。

## 已完成的产品修改

1. **一键生成独立部件预览**：在“拆分部件”中选择当前范围，自动补齐已保存整体组，不必逐块画切割盒。失败组列出原因，保留源网格；预览不修改当前版本。
2. **完整圆柱抱枕重建**：先核对圆柱曲面证据，拟合实际轴线、半径及圆周/轴向起伏，再补端面和缺失背面。避免只把可见半边包成薄壳。不是按名称强套固定尺寸圆柱。
3. **区分重建表面和推测表面**：蓝色是重建外表面，橙色是附近缺少源表面支持的推测区域。全部新面均为重建，不能把蓝色说成原始三角面。
4. **完整组移动与导出**：选中重建部件中的某个技术面片时，自动带上同组接口面，避免移动或下载后丢掉底面。界面按逻辑组计数，保存后的选择不再按面片数量显示多个部件。
5. **保存同一份预览**：保存复用已预览 GLB 的确切字节；绑定版本、源文件哈希和请求范围。范围变化、源变化或预览文件被修改时拒绝保存。后端也阻止直接绕过预览保存新重建。
6. **失败保护与资源控制**：检查闭合、面方向、体积、连通性、自交和相对源网格偏差；保留拒绝原因及测量值。同一服务最多运行一个此类 CPU 预览，复杂输入允许最多六分钟，超时提示缩小范围。

操作位置：工作台 → 采用 AI 整体分组 → 拆分部件 → **生成独立部件预览** → 自动补齐当前范围的部件 → 查看正面、侧面、背面和底面 → 保存候选。涂抹修正继续保留；有未保存选区时先保存分组。

## 实际使用的 AI 与算法

识别沿用本地 **Grounding DINO Tiny + SAM 2.1 Hiera Tiny**：六个有相机标定的视角、掩码对应三角面、跨视角归组和有限范围传播。本轮主要复用已保存的识别结果验证重建，没有重新训练识别模型，也没有用更强模型的名称包装几何处理。

新增重建是 CPU 几何算法：广义绕数估计缺失区域的内外，靠近已观察三角面时用伪法向距离保持原表面细节，再提取等值面。圆柱抱枕使用有几何证据的曲面拟合。`libigl==2.6.1` 安装到隔离的 `.tools/geometry_extra`，未修改 CUDA 模型环境；`manifold3d==3.5.5` 仅用于座面自动切分试验，尚未接入产品操作。

不需要商业 API 密钥。本轮没有将商品图片上传外部服务，没有新增付费 3D 调用。依赖安装说明见 `requirements-geometry.txt`。

## 完整圆柱抱枕的实际测量

- 输出 12800 个三角面；闭合、单一连通体、方向一致、正体积；自交面数为 0。
- 相对源部件包围盒对角线，6,000 个确定性、按面积随机采样的源表面点，到候选表面的距离 p95 为 0.007014，p99 为 0.013681；包围盒变化比为 0.020020。
- 约 51.0% 的候选表面积被标作缺少附近源表面支持。隐藏半边和端面包含推测，真实形状与尺寸没有验证。

这些是对源 3D 的离散测量，**不是实物误差、语义识别准确率或完整 Hausdorff 距离**。保护阈值只是拒绝明显失败的工程规则。允许只移除很小的重建副产物，同时重新检查完整源表面的采样偏差；没有通过丢弃明显背面来凑成一个实体。

## 未采用的尝试与复核结果

| 尝试 | 实测问题 | 处理 |
| --- | --- | --- |
| 直接填洞、平面补面 | 多个样本留下边界，或补面发生自交；部分生成多块明显实体 | 保留日志，不接入新自动补全流程 |
| 单独使用 Poisson 或最近法向距离 | 外形外扩、开口、部分靠枕自交或多块 | 未采用 |
| 只用绕数重建 | 部分表面出现阶梯纹；开口零件的全局体积符号随平移改变，不能用来判定朝向 | 改用观测距离约束，增加平移回归测试 |
| 全局平滑绕数字段 | 细薄包边被抹掉，部分包围盒偏差明显 | 未采用 |
| 按座面高度、凹缝和投影轮廓自动切坐垫 | 皮革样本切出了薄层和残余碎块；灯芯绒样本座面缺块并分成两段 | 未接入产品，不能算坐垫拆分成功 |
| 扩展圆柱边缘归属 | 重新归组后，圆柱拟合候选的 p99 距离比 0.037836、包围盒变化比 0.029705，超过既定保护阈值；真实 UI 复测未满足“三组全部重建”的断言 | **已撤回该归属改动**；拒绝结果、失败 UI 和日志完整保留在 `refined_semantic_v2`、`refined_solid`、`final_ui` |

最终采用的 UI 复测位于 `final_ui_verified`，使用此前保存的稳定 AI 分组快照。没有用失败的新归组替换它。此选择提升了可用重建功能，**没有解决通用部件识别的根本问题**。

## 当前限制与后续优先级

1. **首先解决语义边界**：灯芯绒靠枕仍带长条杂片，椅子仍把椅背/框架合在大组中。应增加可核验的部件标注和多视角一致性约束，不能继续无限放大表面传播范围。
2. **坐垫与座架分开仍未通过**：凹缝和高度仅能提出边界候选，必须有完整侧面和底部证据；源网格形变或粘连严重时需局部形状重建。
3. **纹理模型暂不重建**：当前只处理无 UV、无顶点颜色及普通参数材质的静态部件，避免悄悄丢失纹理。单个部件最多 80 万面，一次范围最多 160 万面和 16 组。
4. **交互性能仍有工作**：较复杂的椅子试跑约 231 秒，耗时受本机并发任务影响；应进一步做后台进度与按组缓存，不能据此给出稳定性能承诺。

本轮交付的是经过测试、可回退的部件重建能力与真实失败证据；准确的全自动沙发坐垫拆分和通用家具部件识别仍是未完成项。
