# 可见表面选择与编辑界面简化 · 2026-11-12

本轮根据实际使用反馈，处理“选桌面时把背后桌腿一起选上”和“生成后仍堆着图片准备、版本、贴图等操作”两类问题。原模型和历史版本保留，新增的是交互与选区保存语义；本轮没有新增 3D 推理。

## 用户操作变化

- 生成成功或打开已有模型后，直接进入模型编辑。左侧参考图片、目标识别、擦背景、生成参数、示例列表不再常驻。
- 需要看图片时点“对照原图”；需要改输入再生成时点“修改图片 / 重新生成”。后者保留图片准备入口，可以返回模型编辑。任务未生成、失败或等待处理时仍显示图片准备与处理原因。
- 右侧只有“换材质 / 拆分部件 / 更多操作”三个入口。颜色与常用质感直接可用；光泽、透明度、贴图、历史、减面、参考视图等按需展开。
- 模型操作改为“查看 / 选部件”“涂抹选择”“框选区域”。默认只选当前看得见的表面。“同时选择背面（穿透）”单独放进选择设置，默认关闭。
- 涂抹或框选后，右侧自动切到拆分部件。输入名称并点“保存选区为部件”，随后自动切到换材质，并将修改范围设为“刚保存的选区”。尚未保存的选区不会直接套用到整个模型。
- 部件名称保留用户输入，例如“桌面局部”；其余网格单独标识。历史操作名称也改为中文。下载入口放在模型标题栏，避免默认界面重复展示相同下载。

## 选择问题的处理

旧选择只检查面心是否落在屏幕画笔或框内，没有判断遮挡，因此桌面后的桌腿也会进入选区。新实现从相机向候选三角面中心发射射线，比较最近相交表面；用 three-mesh-bvh 0.8.3 加速，保持原来的三角面编号。

不会只把错误选区在画面上藏起来：保存进 GLB 的三角面也经过遮挡筛选。选区高亮采用深度检查；新分组记录 selected / remainder 标记与来源 ID，材质修改使用真实新部件 ID。

第一轮使用屏幕深度采样时，在真实高密度桌面上出现零碎漏选，颜色应用后留下白点。这个方案已替换为几何射线查询，失败截图保存在带 `_depth_initial` 的文件中。最终截图已查看，内部白点问题消失，区域边缘仍遵循三角面边界。

## 保留的限制

“只选可见表面”判断遮挡，不自动识别“整块桌面”这种语义。画笔覆盖到露出的桌腿时，仍会选到它；桌面背面和底面需要旋转后补选。选区按完整三角面及其中心归属，不是逐像素涂色，不会切开并封闭实体。透明物体在选择时按实体遮挡；极薄重叠面按数值容差处理，未覆盖所有透明/动画资产。

之前已经保存的旧拆分不会被自动回滚。新界面适用于已有模型，重新涂抹时使用新规则。多图融合、语义拆部件和重建质量仍属于此前报告中的未完成能力。
