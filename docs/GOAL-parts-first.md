# Goal：从图片生成具有完整可编辑部件的家具 3D

## 最终目标

自动识别输入图片中的家具，为每件家具生成对应的 3D 模型。模型应包含具有稳定身份的完整部件，能够独立选择、隐藏、换材质和导出，并能正确装回整体。支持白底商品图、杂乱场景图和一图多件家具。

单张图无法确定的背面、内部连接与真实尺寸，明确标为推测或未验证。“几何闭合”不等于“符合真实制造结构”，不伪造准确率、人工验收或实物精度。

## 主路线

图片 → 家具实例识别与清理 → 整体粗模及完整部件规划 → 在共同坐标、尺度和连接关系下生成独立部件 → 装配 → UV 与材质 → 完整性和输入图对照检查 → 带层级与稳定部件身份的 GLB。

生成前就建立坐垫、靠枕、圆柱抱枕、座架、桌面、支撑、柜门、抽屉和层板等部件身份。技术网格碎片不能直接当作语义部件。普通几何构件可按图像证据拟合，软包部件可采用 AI 重建，不把不同品类都映射到同一个参数模板。

已有整件模型继续支持后期拆分。选区错误通过重新识别或分割改正；形状缺失或粘连通过对应部件的局部重建处理。修复一个部件时优先保持其他部件稳定。

## 实施顺序

1. 检查现有代码、资产与记录，保留原件、失败尝试和来源。
2. 先处理两款失败沙发：区分完整坐垫、方靠枕、圆柱抱枕和座架，检查前、侧、背、底部归属。
3. 验证本地 AI 语义规划、精细分割与部件生成；原生联合生成效果不足时评估逐部件生成及装配约束，不能仅凭模型名称声称支持。
4. 扩展桌、椅、柜，处理桌面、支撑、柜门、抽屉等结构与杂物排除。
5. 接入实际可用的任务、进度、预览、返工与导出流程，保持已有工作台可用。
6. 做代码 review、回归、真实浏览器操作与多家具实测，继续修复实际发现的问题。

## 验收要求

- 不少于 10 个不同家具设计的固定实测集，含两款失败沙发及桌、椅、柜；覆盖白底图、杂乱背景和多家具实例。
- 每例记录家具实例、部件清单、漏识别、误合并和误拆分；区分识别、生成、装配、材质各阶段的覆盖情况。
- 逐部件检查闭合、连通性、自交、异常穿插、悬空及缝隙，提供装配与前、侧、背、底面证据。
- 部件可独立选择、隐藏、换材质和导出，局部修改不误改邻件；UV 和纹理尺度可调整，GLB 保留部件层级与身份。
- 对原图同角度渲染进行对照；同图拟合指标不能冒充独立实物准确率。
- 既有参考模型、不同视角、不同 seed、缓存复用或测试副本不能冒充不同新家具，也不能替代本轮真实生成实测。
- GLB 有效、能打开、契约测试通过或旧编辑功能通过，均不能单独作为完整部件生成验收。

## 记录和边界

自主推进已授权的本地实现、修复、review 和必要测试。记录真实用时、实验矩阵、失败原因、修复结果、前后对比和详细中文报告；不用凑时长代替改进。未通过的要求保持未完成，不因阶段成果而提前关闭 Goal。

当前服务使用 8001，不操作 8000。不覆盖原始资产，不提交或清理无关文件，不擅自使用付费服务、向外部服务上传图片或引入费用。允许范围内下载公开源码和模型，并保留许可、固定版本和哈希。
