# 点选部件（几何辅助）审查与验收 · 2026-11-12

本轮增加基础版“点选部件”，保留涂抹修正。它按已有网格边界、连通关系和近似平面判断区域，不使用语义分割模型，也不要求 API 密钥。它能减少桌面等平面区域的手工涂抹，但没有实现对所有家具部件的一键语义识别。

## 使用方法

1. 在已有模型中点“点选部件”，再点击目标表面。拖动仍然可以转动模型，不会把拖动当成点选。
2. 已拆好的部件会直接成为材质修改范围，不需要再次拆分。未拆分的网格则尝试找独立连通区域或连续平面。
3. 扩选成功会显示紫色。确认后命名保存，再换材质；少选或多选时可以在“点选设置”调整范围，或用“涂抹修正”。
4. 默认每次点选替换原选区；需要合并多个区域时勾选“追加到已有选区”。框选保留在涂抹工具的“选择设置”里。

“连续平面”不是完整实体部件：桌面上表面可能被选出，圆边、侧边和底面不保证包含。独立连通区域会包含该区域的背面；涂抹仍默认只选可见表面。沙发坐垫、弧形桌腿等连体曲面没有稳定边界时，界面会提示无法自动选出完整部件，并保留原选区。

## 实现与保护

- 构建几何面邻接图，按位置焊接 UV / 法线接缝的重复顶点，不修改原索引和坐标。
- 非流形边作为边界，避免随意跨越；独立连通区域与整网格分开判断。
- 平面扩展同时约束种子法向与平面距离，而不是只按相邻面局部角度逐步爬过圆角，减少从桌面蔓延到桌腿的风险。
- 点选失败不自动选整个模型，也不创建版本。单网格超过 100 万面或选区超过 50 万面会提示先减面或改用涂抹。
- 所有候选都需要用户检查。不会自动命名成“桌面”“坐垫”来暗示语义已经识别。

## 验证结果

- 新增几何对照 **6 项通过**：同一网格中的独立几何块；从第 0 面开始点选；索引保持不变；非索引与非均匀/镜像变换；连续平面在下凹连接处停止；有机球面拒绝假完整部件；非法种子拒绝。其中一项含多条断言，计数按测试项目而非断言数量。
- 原可见表面选择回归 **9 组通过**，保留画笔/框选的遮挡、斜面、正交/透视、变换和索引保护行为。
- 浏览器 **10 组检查通过**：真实圆桌点选、范围收缩与追加模式、清空后不复活旧种子、撤销重做、保存与局部材质、已有部件直接点选、点选模式拖动转动、涂抹与框选保留、软包失败提示、390 像素手机无横向溢出。最终页面错误为 0。
- 另测点选后用涂抹擦除：从 102,276 面修正为 82,704 面，返回点选工具后修正保留；旧种子不会通过范围控件覆盖这次修正。
- 前端生产构建通过，仍有 JS 包大小提示。没有声称测得真实用户操作耗时提升或选择准确率。

真实圆桌初次在正常范围下点击得到 102,276 面；后续浏览器测试调整到较小范围后再次点击并保存了 101,730 面。保存结果的世界坐标三角面多重集合与原始模型一致（373,104 面），原文件 SHA256 保持不变，只有所选区域材质改变。选区顶点处在模型总高度约 99.76% 到 100.00% 的顶部薄层，未包含下方桌腿。

导出 GLB 规范校验为 0 errors / 0 warnings；原有 POSITION / NORMAL 的 bufferView.target 有信息提示。这证明文件与本次编辑有效，不能证明重建形状或材质与实物一致。

## 代码审查与实测发现的修复

- 点选后撤销到空选区，操作栏曾随选区一起隐藏，导致无法重做。修复为点选模式下保留操作栏，按真实历史状态禁用或启用按钮；浏览器重跑通过。
- 从点选拖动切到涂抹，旧指针起点曾残留，移动时访问空笔迹数组产生错误。修复为每次抬起先清除起点，并对空笔迹保护；拖动、切换、涂抹重跑没有页面错误。
- 追加模式下缩小范围可能把旧大范围再次合进来。现在按该次点选前的基准选区重算，正常 / 更大 / 更小的浏览器样本数量分别为 102,276 / 102,659 / 101,727，收缩有效。
- 清空或涂抹后旧种子可能再次改变选区。现在清空、撤销、重做或涂抹会使旧点选上下文失效，范围控件禁用，需重新点击模型；独立修正上下文测试通过。

首次失败记录分别保存在 `browser_checks_initial.json`、`browser_checks_pointer_initial.json`；最终结果为 `browser_checks.json`。没有删除旧模型、失败版本或测试证据。

## 仍可优化的重点

下一步建议做“候选部件清单”：生成后先提出候选区域，允许逐个高亮、合并、拆分、命名，再统一换材质。要稳定列出“桌面、桌腿、坐垫”等名称并包含侧面/背面，需要真正的语义部件分割、跨视图关联和有标注样本的验收，当前尚未实现。继续堆几何阈值不能等同于完成这项能力。
